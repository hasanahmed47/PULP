# Source guide

Yeh guide project ka code map hai. Paths repository root se hain. React components props lete hain aur JSX return karte hain; event handlers state/callback update karte hain aur usually koi value return nahi karte. Effects listeners, timers aur animations set up karte hain; unka returned function cleanup karta hai. Neeche har file ke special inputs, outputs aur dependencies diye hain.

## Layout and units

All application CSS `src/styles/` mein hai. `tokens.css` shared colours, fonts, spacing aur radii define karta hai. Dimensions 16 CSS pixels = 1rem ke baseline par converted hain; root font size fixed nahi hai. Percentage, viewport, container and em units apne original responsive purpose ke liye retained hain.

`CanScene` ka relative `.can-scene__stage` canvas, fallback aur dono absolute splash layers ka common coordinate system hai. Controls ki reserved height stage se ek baar subtract hoti hai. Compact container query isi stage ko resize karti hai. Canvas par extra mobile bleed nahi hai. Ground 86% stage height par hai: current camera se can base approximately isi position par project hota hai. Camera pose, FOV ya model height change karte waqt ground bhi verify karein. The renderer uses measured stage dimensions and `setSize(width, height, false)` so CSS owns the display size.

IntersectionObserver `rootMargin` only pixels/percentages accept karta hai, is liye uske strings retained hain. Pointer coordinates, canvas drawing buffers, image intrinsic width/height, SVG viewBox coordinates and Three.js world units CSS layout dimensions nahi hain. Inhein rem mein convert nahi karna. GSAP/ScrollTrigger runtime transforms aur pin-spacer inline styles generate karte hain; static presentation CSS mein hai. Custom SVG artwork (loader, ribbon and cutaway mask) remains SVG; UI icons use Lucide.

## CSS files

CSS files receive class names/data states and inherited tokens, and produce browser presentation; they return no JS values. Each component/section imports its matching file. Every file below depends on `tokens.css` unless stated otherwise. Media queries adjust compact layouts; reduced-motion blocks disable or shorten motion.

| File under `src/styles/` | Blocks and responsibility |
| --- | --- |
| `tokens.css` | Tailwind theme fonts/ink; root palette, typography, spacing and radii; flavour attributes supply colour/pale/accent/tilt; compact viewport adjusts gutters/radius. Depends on the global Tailwind import. |
| `global.css` | Imports Tailwind/tokens; base typography, sizing/reset, grain overlay, focus/selection, page padding, headline/wordmark, pills and organic shape utilities. |
| `App.css` | Stable scrollbar gutter, root loading scroll lock and horizontal overflow containment. The content uses clip so sticky sections keep the viewport as their scrolling ancestor. |
| `DeferredHighlights.css` | Reserves the same card height as the real carousel while its JavaScript loads. Shared HighlightsCarousel.css supplies matching heading/spacing metrics. |

## Audit decisions

Removed `sections/Mascot.jsx`, its CSS and `hooks/useFruitParallax.js`: none was reachable from the application entry. The asset checker previously required a missing mascot image; it now validates every asset declared in media.js instead. The GoodInsides test now reads the actual `data-index` eye state instead of an obsolete inline CSS variable.
