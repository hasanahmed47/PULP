# PULP — image and video prompts

Use these in Higgsfield's image generation/editing and image-to-video tools. These are prompts for you to run; no Higgsfield assets or paid generations have been created for this handoff.

The supplied demo screenshots establish the visual reference: oversized condensed headings, realistic slim cans, playful soft-serif can lettering, tactile fruit cutouts and a rounded orange mascot. Use them as style references, without copying the video player interface, shopping controls or extra demo sections.

Start with **one approved red master can**. Attach that exact image whenever a prompt below says “reference.” Do not generate the four cans independently. Reject misspelled labels, invented text, mismatched proportions and fake checkerboard transparency before moving on.

The site already includes editable illustrations, so you can run the project now. These assets replace those illustrations with the photorealistic direction from your brief.

## Export guide

| Asset | Source filename | Canvas | Output |
| --- | --- | --- | --- |
| Red master can | `blood-orange-can.png` | 1200 × 2000 | Transparent PNG |
| Yellow can | `passionfruit-yuzu-can.png` | 1200 × 2000 | Transparent PNG |
| Blue can | `blueberry-can.png` | 1200 × 2000 | Transparent PNG |
| Green can | `lime-basil-can.png` | 1200 × 2000 | Transparent PNG |
| Red interior | `blood-orange-cutaway.png` | Identical to the red master | Transparent PNG |
| Each fruit group | `<flavour>-fruit.png` | 1200 × 1200 | Transparent PNG |
| Mascot | `orange-mascot.png` | 1400 × 1400 | Transparent PNG |
| Each wrap | `<flavour>-wrap.png` | 2048 × 1424 | Opaque, flat artwork |
| Film poster | `pour-poster.jpg` | 3840 × 2160 | JPG or PNG |
| Film | `pulp-pour.mp4` | Native 3840 × 2160 | Silent H264 MP4 |

Replace `<flavour>` with `blood-orange`, `passionfruit-yuzu`, `blueberry` or `lime-basil`.

Use actual alpha transparency. A white background or painted checkerboard is not transparency. Select resolution and output settings in the tool as well as stating them in the prompt; a prompt cannot guarantee native 4K or perfect pixel alignment. If a generator cannot export native 4K, retain its actual resolution and tell me. Do not upscale it and call it native 4K.

## 14. Browser-ready export

If the original is already native 3840 × 2160, the following command converts it to browser-compatible H264 while keeping its resolution:

```bash
ffmpeg -i original-pour.mov -t 6 -an -c:v libx264 -crf 20 -preset slow -pix_fmt yuv420p -movflags +faststart public/media/pulp-pour.mp4
```

Do not add an upscale filter to satisfy the native-4K requirement. Check the original export first. For a lighter phone version:

```bash
ffmpeg -i public/media/pulp-pour.mp4 -an -vf scale=1280:720 -c:v libx264 -crf 23 -preset slow -pix_fmt yuv420p -movflags +faststart public/media/pulp-pour-mobile.mp4
```

Extract a poster from the finished film if its first frame is good:

```bash
ffmpeg -i public/media/pulp-pour.mp4 -frames:v 1 -q:v 2 public/media/source/pour-poster.jpg
npm run assets:optimize
```

Finally configure `film` and optionally `filmMobile` in `src/data/media.js`, run `npm run check:release`, and watch the entire loop on desktop and phone before deployment.
